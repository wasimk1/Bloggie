# Bloggie – ASP.NET Core MVC

Bloggie is a web-based blogging application built using ASP.NET Core MVC. It allows users to create, manage, and explore blog posts through a simple and user-friendly interface.

## Tech Stack

- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- HTML, CSS, Bootstrap
- LINQ

## Features

- Create, edit, view, and delete blog posts.
- Manage blog categories and tags.
- SQL Server database integration using Entity Framework Core.
- MVC architecture with separation of concerns.
- Responsive user interface.

## Getting Started

1. Clone the repository:

   `git clone https://github.com/wasimk1/Bloggie.git`

2. Open the solution in Visual Studio.
3. Configure your SQL Server connection string.
4. Apply EF Core migrations if required.
5. Run the application.
